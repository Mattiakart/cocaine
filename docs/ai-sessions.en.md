### AI sessions in the notch

- **Every session, the ones that need you first.** The island's Home tab and the panel's Agents card list all your AI sessions (no longer just three), scrolling when there are many: waiting for you, then failed, then working, then finished, newest first. Up to 100 are kept; finished ones fade after 30 minutes.
- **Survives a restart.** The list is saved (privately, atomically) and comes back when Cocaine reopens; entries from before the restart show ↺ and their age. A session whose process has ended is dropped; when Cocaine can't check, a "working" one is dropped after 2 hours and a "waiting" one after 6 (24 hours if its process is still running). This also stops Smart Triggers from keeping the Mac awake for a session that has already quit.
- **Click to go back.** Clicking a session (or a recent alert) brings forward where it runs: the exact tab in Terminal or iTerm2 (needs *Automation* permission for that app, asked the first time; if refused, Settings opens on Privacy & Security → Automation), the tmux pane, the WezTerm pane, or the VS Code / Cursor / Windsurf window with its folder. Otherwise it brings the app forward, or opens the session's folder in Finder, and always says what it could and couldn't do. Limits: an IDE's built-in terminal panel, JetBrains IDEs, Ghostty, kitty and Warp can only be brought forward as an app; sessions started before this version (or by scripts) don't say where they run. The full-screen alert flash itself isn't clickable (it would swallow your clicks); use the session or the recent alert.
- **Answer from the notch** (AI alerts → When, off by default). Claude Code (2.0.45 or newer) and Codex requests for permission show up with **Allow** / **Deny** / **In the terminal**; Claude Code's MCP questions with one choice or yes/no field get a button per answer (bigger forms can only be declined there). It uses only the tools' documented hooks (Claude Code `PermissionRequest` and `Elicitation`, Codex `PermissionRequest`). Nothing is ever approved on its own: if you don't answer within 2 minutes, if Cocaine isn't running, or if anything goes wrong, the tool shows its own prompt in the terminal as usual. While a request waits in the notch, the terminal prompt isn't shown yet — use **In the terminal** to hand it back at once; if you're already in that session's terminal app, the request goes straight to the terminal. Claude Code's questions asked with AskUserQuestion can't be answered from outside (no documented hook for it): they are announced, and clicking goes to the terminal.
- **Security.** Requests travel over a socket in Cocaine's private folder that only your user can open; each answer is signed with a per-install key and tied to that one request, so a late, repeated or forged click can't approve anything.
- **After updating,** Codex asks once to trust Cocaine's changed hooks (/hooks, or Settings → Hooks in the ChatGPT app). The request hook runs Cocaine's own app binary, so it works only from an installed copy (Applications); turning AI alerts off removes it with the others.
- **What "Allow" shows.** The notch offers **Allow** only when the whole request fits in one short field (up to 120 characters; line breaks show as ⏎), so you never approve something you can't see — for example a file's full contents, an edit's new text or a long, multi-line command. Anything bigger goes straight to the terminal's own prompt.
- **Session folders.** Clicking a session opens only plain folders, never an app or bundle named by a link.
